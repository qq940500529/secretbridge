# Community conduct

Be respectful, constructive and specific. Welcome newcomers and accessibility needs. Critique ideas and code, not people.

Harassment, discrimination, threats, doxxing, credential sharing and unauthorized testing against third-party systems are not acceptable. Do not pressure contributors to disclose personal identity or private business data.

For non-sensitive moderation concerns, contact the repository maintainer through a GitHub issue. Request a private channel without naming affected people or publishing evidence if the matter is sensitive. Security issues follow SECURITY.md.

The maintainer may request edits, lock a discussion, remove harmful content or restrict participation proportionately. Explain decisions when doing so will not expose private information; allow a respectful request for reconsideration. These rules apply to project spaces, not to unrelated private activity.
