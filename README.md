# SecretBridge 社区清单：云端补充验证证据

本轮可执行范围全部通过；这是 Linux 云端自动化补充证据，不代表社区清单中的真实桌面、原生凭据库、完整重启或跨平台条目已完成。

报告日期：2026-10-06（Asia/Hong_Kong）。测试浏览器使用 UTC，截图中显示的 2026-10-05 晚间时间是 UTC。

## 测试对象与方法

- 版本：`0.3.0-beta.5`。
- 源码：[`da8121e04af59b585c913598150d575fc9a0647f`](https://github.com/qq940500529/secretbridge/tree/da8121e04af59b585c913598150d575fc9a0647f)。测试始终使用该提交，源码工作区未改动。
- 系统：Debian GNU/Linux 13 x86_64 云容器；与 Ubuntu 24.04 桌面验证目标不同。
- 工具：Rust 1.98.0、Node 24.21.0、pnpm 11.23.0、Python 3.12.14、Playwright 1.63.0。
- 浏览器：系统 Chromium 151.0.7922.173，无头模式。没有验证 Firefox/WebKit，也没有将系统 Chromium 描述为 Playwright 锁定下载的浏览器。
- 数据库：仅回环开放的一次性 PostgreSQL 17.11、MySQL 8.4.11，短期测试 CA、合成凭据；TLS 验证保持开启。
- SSH/HTTP：测试夹具实现的本机真实协议服务，实际 TCP/SSH/HTTP 通信；不等于独立服务器上真实用户账号的端到端部署。
- 所有浏览器界面流程使用模拟 API；原生协议和持久化结果由 Rust 测试单独验证。没有使用真实用户凭据，没有自动设置用户的真实 PIN 或批准真实业务操作。

## 实际执行数量

- Rust library：218 passed、0 failed、15 ignored。忽略项包括另行运行的数据库场景，以及没有运行的原生凭据库等；保留原始分类。
- 终端集成：合成终端洪泛/重连/取消 1 项、真实 Bash PTY 1 项通过。
- 并行取消：3 个独立运行，每轮 1 项测试通过。
- 同目录规模：2 个独立测试进程，每轮 1 项测试通过；每轮增加 2,000 次合成审批/运行，共 4,000 次。
- 数据库：11 项连接器测试、1 项 MCP 测试通过。过滤目标之外的 `running 0 tests` 不计为通过项。
- Chromium：6 个完整工作流通过；另一次截图重新采集执行工作台/SSH 的 2 个完整工作流，断言均通过。没有修改测试源码、跳过断言或放宽时间限制。

## 同目录资源趋势

Linux 页大小为 4,096 bytes。目录大小包含数据库及当时的 WAL/SHM。

| 阶段 | 审批/运行数量 | 阶段秒数 | 数据库+WAL/SHM bytes | RSS MiB |
|---|---:|---:|---:|---:|
| 1 | 1,000 | 3.099 | 6,000,288 | 13.395 |
| 2 | 2,000 | 5.364 | 7,683,840 | 14.094 |
| 3 | 3,000 | 7.768 | 9,383,848 | 14.223 |
| 4 | 4,000 | 9.802 | 10,997,576 | 14.574 |

2,000 条记录时备份为 3,481,600 bytes；4,000 条记录时备份为 6,795,264 bytes。两轮都成功复核首尾脱敏输出及备份恢复。有限样本不支持无内存泄漏或无限规模结论。
