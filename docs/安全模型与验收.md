## 保护对象与信任假设

保护密码、API令牌、私钥、Cookie、数据库连接凭据、认证输入、可代用凭据的连接或agent句柄，以及审批能力。也保护目标系统数据、命令执行权限、策略与审计完整性。

默认不信任：模型生成的命令和参数、业务文件中的指令、终端输出、远程错误信息、工作区脚本、AI可编辑的配置、远程提示的“请输入密码”。收到业务系统输出不是获得执行新操作的授权。

可信基础：用户操作的管理UI、经审核的代理和适配器、受保护策略、操作系统身份隔离、经验证的目标端点。不能在这些组件已被恶意修改时继续声称安全。

## 保证范围与限制

可以设计并测试的目标：模型工具协议无秘密值；授权请求之外不取密；密码不进入argv、通用环境、历史、正常日志；所有释放的结果经过批准字段和统一脱敏；不存在未授权的密钥读取接口。

不能普遍承诺：给任意程序密码之后仍阻止所有外泄；用正则识别所有变换后的密码；防御有调试权限的同身份进程、管理员或内核攻击；保证第三方程序从不落日志、崩溃转储或写交换页；网络连接中断后知道远端操作是否已提交。

Windows凭据库按登录身份提供访问，DPAPI保护范围也不是“只有本应用能读取”。如果AI具有用户级任意执行能力，仍可能直接调用这些系统API；按SID设置ACL无法隔离同SID的恶意程序。因此必须先约束AI执行权限，再讨论真实凭据安全。[CredReadW](https://learn.microsoft.com/en-us/windows/win32/api/wincred/nf-wincred-credreadw)、[DPAPI](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata)

OWASP提出秘密应最小授权、可撤销、可轮换且不直接记录。密桥据此将凭据生命周期与审计纳入产品，而不只做登录自动化；下表为本项目设计，不是对OWASP认证或安全保证的声明。[Secrets Management](https://cheatsheetseries.owasp.org/cheatsheets/Secrets_Management_Cheat_Sheet.html)

## 威胁与控制

| 威胁 | 必须采取的控制 | 残余风险／检查点 |
|---|---|---|
| AI诱导输出密码或编码后外传 | 不开放任意携密shell；固定适配器与结构化结果，出站限制 | 仅做原文替换不能通过此项 |
| AI绕过代理读取库／进程 | 独立身份、受限AI环境、进程与文件访问隔离 | 同账号兼容模式不满足强保护 |
| 假UI审批／复用批准结果 | 管理与执行通道分离、批准绑定请求摘要、单次／限时使用 | AI能控制管理UI时审批失去意义 |
| 可执行文件、配置或DLL被替换 | 受保护安装目录、固定依赖与环境、执行前完整性核对 | 仅固定路径不足以防TOCTOU |
| 目标地址或重定向被改 | 目标绑定、TLS／SSH主机验证、DNS及实际连接终点约束 | 不允许跳过证书错误后继续携密访问 |
| 伪造密码提示 | 可信适配器与认证状态机，必要时可信UI接管 | 禁止任何终端遇到Password就自动填写 |
| 密码进入进程参数和子进程 | 禁止密码argv；限制环境与句柄继承、子进程树 | 环境变量不是普遍安全替代品 |
| 流式块边界、ANSI控制绕过 | 跨块状态、统一UTF-8与控制序列处理，失败阻断 | 未知编码不能靠有限匹配保证识别 |
| terminal/日志/导出绕路泄漏 | 输出发布前统一管道，不保存未过滤原文 | 审计与前端异常上报同样需过滤 |
| 远程输出操纵剪贴板或链接 | 禁止自动OSC52、自动URL访问、HTML与外部资源加载 | xterm.js不是安全沙箱 |
| 会话ID越权、多客户端串话 | 归属校验、租约、客户端隔离、逐请求授权 | session_id不作为bearer凭证 |
| 重连重放写操作 | 幂等键、运行状态、未知结果需人工处理 | 首版不自动重试非幂等操作 |
| 锁库后认证会话仍可执行 | 锁定／撤销联动会话终止，确认远端状态 | 关闭本地连接不能撤销已提交业务操作 |
| 插件、数据或文档提示注入 | 外部内容只作为数据，不自动修改策略／获得权限 | “来自官方文档”也不能替用户审批 |
| MCP客户端扩大工具权限 | 固定工具与JSON Schema；不提供审批决定、取密、自由SQL／Shell或目标地址参数 | 同用户客户端仍可发起大量待审批请求，容量与人工核对必须保留 |
| MCP stdout混入日志破坏协议或泄漏 | stdout仅承载JSON-RPC，诊断统一写stderr；适配器错误映射为固定错误码 | 宿主对stderr的保存与上传策略仍须单独核对 |
| 明文临时文件与崩溃报告 | 默认禁用；例外隔离ACL、生命周期清理、无原始dump上传 | 崩溃和设备残留不能完全消除 |
| 业务数据不含密码但不宜外发 | 结果列白名单、限量、人工模式和项目策略 | 不能以脱敏成功代替数据授权 |

## 验收清单

> [!CAUTION]
> 不要使用真实密码验证过滤效果。攻击测试必须使用合成秘密和获授权的测试目标；公开报告只保留脱敏复现。

测试结果使用 `未运行 / 通过 / 失败 / 不适用（说明原因）` 四种状态。以下编号用于追踪覆盖范围，不表示已经通过。


测试仅使用明显虚构的合成秘密，不能把真实密码交给测试脚本或AI用于“验证脱敏”。测试输出不得回显合成秘密原值，报告记录测试ID与通过／失败。

### S：安全阻断

- S01：AI接口清单没有get_secret、解密、环境导出、审批决定、任意SQL／Shell或原始认证流工具。`alpha.13`已用协议级工具清单与输入Schema回归覆盖当前8个MCP工具。
- S02：未授权客户端、跨项目客户端、跨会话客户端均无法执行或读事件。
- S03：拒绝、过期、重放和参数变更批准；撤销后的排队任务也不可开始。
- S04：命令参数、环境快照、shell历史、UI状态、日志、通知、导出、错误栈无秘密原值。
- S05：在每个字节位置拆分秘密，分别测试UTF-8、stdout/stderr分片、取消尾部、截断与超长输出。已知模式不先泄漏前缀再补打码。
- S06：Base64、百分号编码、分字符、文件和网络外传尝试由执行权限／出站策略阻止；不能只期待打码正则覆盖。
- S07：恶意response file、配置文件、PATH、插件、DLL、工作区替换程序、链接／重解析点不能改变被批准的执行器。
- S08：模拟恶意服务回显密码、伪造提示或重定向；返回固定安全错误，不暴露认证载荷。
- S09：OSC52、链接、HTML与终端控制序列不能自动操作剪贴板／网络／可信UI。
- S10：带凭据会话拒绝raw write与普通会话接管；普通会话无法读取库、策略、代理内存或使用认证句柄。
- S11：测试身份直接调用凭据库API、读取DPAPI数据、请求调试代理、访问管理管道均失败；若以同账号运行导致成功，判定隔离失败，不上线真实凭据。
- S12：锁定、停用、过期、轮换使新授权失效；已有携权会话按策略终止；失败时UI显示未撤销完成。
- S13：生产目标、新目标、证书／指纹变化必须重新确认；后台程序不得根据远端提示自行信任。
- S14：前端无明文持久存储、远程埋点、热更新脚本；管理窗口权限不能被终端窗口调用。发布包不启用生产调试泄密功能。

### T：持久化与可靠性

- T01：普通终端cd后下一请求保持目录和普通环境，长任务跨AI调用持续运行。
- T02：关闭UI再打开后同一PID／会话仍在；终端不依赖父命令行窗口。
- T03：MCP连接中断重建不重复执行任务，事件cursor无静默丢失或跨会话混入。
- T04：代理崩溃后会话明确lost，子进程按设计清理；重启电脑只恢复元数据，不能假装原事务仍在。
- T05：大量输出背压、磁盘满、编码错误、PTY挂起、取消、超时均有明确终态和安全输出。
- T06：两个客户端同时写输入时只有租约所有者获准；用户接管时AI输入被拒绝。
- T07：远端写入结果不确定时返回unknown，不自动重试；取消区分“请求已收到”和“执行已停止”。
- T08：普通终端退出码未知时如实报告，伪造shell提示与完成标记不造成假成功。

### U：UI与交付

- U01：中文长文、长错误和大字号可读，100%—200%DPI按钮不被裁切，审批键盘可操作。
- U02：密钥录入保存后界面不回填旧密码；取消表单也清理可清理状态；默认没有明文导出。
- U03：窗口关闭、退出程序、停止代理含义不同；真实停止动作前显示影响范围。
- U04：安装升级不自动迁移其他项目凭据，不上传数据库或诊断包；卸载保留／删除用户数据由用户明确选择。
- U05：安装包标版本、哈希与构建输入；检查依赖许可证、签名／更新来源、SBOM及高危漏洞。

## 试点准入与事件响应

自动化测试与公开证据仅使用假凭据。`alpha.13`开发构建允许用户主动录入真实密码，并通过Web审批或MCP请求链执行固定PostgreSQL只读连接检查，但在S类阻断检查、T01—T06及三平台身份边界完成前，不得把它视为生产安全能力。MCP不能作出审批决定；用户必须在本机Web控制台核对并处理待审批记录。进入真实业务试点前，用户必须明确选择测试系统并创建短期、只读、最低权限身份；不得从既有业务系统、批处理、聊天历史或截图自动导入已有密码。适配器只允许固定`SELECT 1`，真实数据库错误原文与结果行不得返回前端或模型。

发现可能泄露时：停止相关新任务→隔离受影响会话→提示用户在源系统撤销或轮换→保留不含秘密的审计证据→评估远端已发生操作与数据访问→修复并重跑相关用例。不把“把日志中的密码删掉”当成事件已解决，不未经批准重写用户Git历史或删除系统记录。

## 评审记录要求

每项测试记录提交号、目标平台、合成输入、预期行为、实际结果、证据位置与评审者。失败项须关联问题和修复验证；未运行项标记为未验证。M0已覆盖一次性配对、错误Origin／令牌拒绝、PTY重连／租约／有界回放、2 MiB输出洪泛和挂起子进程取消；`alpha.11`以合成秘密覆盖只写接口、无读取路由、版本冲突和SQLite不保存明文；`alpha.12`以替换执行器覆盖PostgreSQL策略、审批、内部取密、单次运行、固定结果、取消和安全事件；`alpha.13`通过内存stdio双工连接覆盖精确工具清单、输入Schema、未批准执行拒绝、Web侧决定后的单次运行／取消以及敏感描述不进入MCP结果。上述测试不会发出真实网络连接。系统凭据库三平台实际行为、操作系统身份隔离、MCP重连生命周期、长时间浸泡、真实目标及第三方安全审计仍未完成。
