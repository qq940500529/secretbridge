# SecretBridge 开发设计

[项目首页](../README.zh-CN.md) / [文档中心](README.md) / 开发设计

本文说明 `0.1.0-alpha.29` 的真实实现边界和接下来扩展核心功能时必须遵守的模块合同。目标架构见[成熟态软件架构与功能说明](成熟态软件架构与功能说明.md)，开发顺序见[功能优先路线图](../ROADMAP.md)。

## 当前组件

| 组件 | 位置 | 责任 |
|---|---|---|
| 核心状态类型 | `crates/secretbridge-core` | API 版本、运行模式和公开状态 |
| Web/HTTP 服务 | `crates/secretbridge-server/src/lib.rs` | 配对、会话、Origin、API、WebSocket 和任务调度 |
| 配置目录 | `catalog.rs` | SQLite schema v14、凭据引用、目标、模板、审批、运行和事件 |
| 系统凭据库 | `secret_store.rs` | 按不透明 UUID 写入、取得和删除秘密 |
| PostgreSQL 适配器 | `postgres.rs` | TLS 固定只读连接检查和私有 CA |
| HTTP 适配器 | `http_task.rs` | 固定原生请求、协议插槽、普通参数、字段筛选和固定错误结果；复用 command.rs 的执行生命周期 |
| SSH 适配器 | `ssh_task.rs` | 固定主机指纹、协议认证、POSIX 逐项引用与分流脱敏；取消感知运输流关闭真实连接 |
| SFTP 适配器 | `sftp_task.rs` | 复用 SSH 连接与认证，固定单文件分片传输、原子提交、有界清理和不含正文的结果 |
| Git 适配器 | `git_task.rs` | 固定 HTTPS 远端、分支与操作；构造环境认证头与已知认证表示过滤表，复用本机进程执行生命周期 |
| PTY 管理 | `terminal.rs` | 系统Shell探测与启动、会话元数据、重连、游标、输入租约和输出边界 |
| MCP/IPC | `mcp.rs` | MCP stdio 工具、本机 IPC、连接文档和代理生命周期 |
| Web 控制台 | `web/src` | 凭据、目标、模板、审批、运行、审计和终端界面 |

已删除的安全验证中心、平台证据、试点准入和试点活动不属于当前产品。schema v12 会从旧数据库中删除对应表，不再提供兼容 API。

## 进程结构

后台代理由无参数的 `secretbridge-server` 启动，持有：

- 回环 Web 服务；
- SQLite 连接；
- 操作系统凭据库适配器；
- 运行取消注册表；
- PTY 会话；
- 本机 IPC 服务。

同一个可执行文件以 `--mcp-stdio` 启动时只运行轻量 MCP 桥接。桥接从应用数据目录读取临时连接文档，经 Windows 命名管道或 Unix domain socket 调用后台代理。MCP 断开不会停止代理、Web 控制台或已有任务。

## Web 信任边界

- HTTP 只绑定 `127.0.0.1`；
- 启动令牌放在 URL fragment，服务端日志和 HTTP 请求看不到它；
- 令牌只能配对一次，换取短期页面会话；
- 修改请求同时要求页面会话和精确 Origin；
- 页面会话只存内存，可撤销、过期，服务重启后失效；
- Web 静态资源随本地二进制提供，不加载远程运行时代码。

这些是本机 Web 应用的基础边界，应保留，但不在界面中包装成独立验证产品。

## 配置与秘密

SQLite 保存：

- 凭据名称、类型、用途、是否已配置和不透明 ID；
- 连接目标的非秘密元数据；
- 操作模板、审批、运行状态和固定事件；
- 对象版本和时间。

SQLite 不保存密码、令牌或私钥原文。秘密进入操作系统凭据库，Web API 只允许设置、覆盖和清除，没有读取路由。服务内部执行器可按 UUID 取得秘密，但调用方拿不到返回值。

配置对象使用乐观版本控制。凭据轮换或清除会更新关联目标版本，使旧审批无法继续执行。

## schema v14

新数据库直接创建核心表并标记 schema v12。旧 schema v1—v7 先完成核心迁移，再升级到 v12；旧 schema v8—v11 删除以下废弃表：

- `security_validation_runs`、`security_validation_checks`；
- `pilot_readiness_snapshots`、`pilot_readiness_checks`；
- `platform_boundary_snapshots`、`platform_boundary_checks`；
- `pilot_campaigns`、`pilot_scenario_evidence`。

迁移不删除凭据引用、目标、模板、审批、运行和安全事件。schema 高于当前版本时继续拒绝启动，避免未知降级。

v13 扩展模板的 `command_json` 配置与明确的 `sanitized_output` 返回范围，新增 `command_slots` 引用关系和有界的 `run_output` 分片表，以及程序 `exit_code`。升级时重建操作／结果约束表并复制原有工作流记录。只有过滤后的输出可以写入分片表；凭据原文仍不进入 SQLite。轮换或清除插槽凭据会递增关联模板版本，使旧审批失效。

`command.rs` 复用现有审批、幂等与运行驱动，负责进程启动、四种注入、并发限额、取消超时及临时材料清理；`redaction.rs` 在输出流进入 UTF-8 解码与持久化前过滤已绑定秘密。普通 PTY 不接收这些注入值。详细合同见[凭据命令任务](凭据命令任务.md)。

v14为审批增加授权方式和已解析普通参数JSON，重建运行表以移除审批ID全局唯一约束，同时保留幂等键、退出码、事件及输出引用。事务内仅对限时授权允许再次创建运行；已有审批继续单次消费。`parameters.rs`负责普通参数定义校验、默认值解析和有界快照。完整合同见[参数化任务与授权](参数化任务与授权.md)。

## 当前任务执行链

PostgreSQL 固定检查已经贯通 Web 与 MCP 请求链：

1. 用户创建凭据引用并写入密码；
2. 用户创建 PostgreSQL 目标与固定操作模板；
3. AI 或 Web 创建审批请求；
4. 用户在 Web 中批准；
5. AI 或 Web 使用审批ID与幂等键创建运行；
6. 后台代理取得密码并调用原生 PostgreSQL 适配器；
7. 适配器在可串行化只读事务中执行固定 `SELECT 1::INTEGER` 并回滚；
8. 调用方只收到枚举结果，原始数据库错误不越过适配器。

操作支持超时、取消、审批撤销和服务重启后的中断状态。`SECRETBRIDGE_POSTGRES_CA_CERT`可指定受限的私有 CA PEM；未设置时使用平台信任根。

## 当前真实 PTY

正式运行时的PTY按当前平台暴露固定Shell集合：Windows为PowerShell和CMD，Linux为Bash，macOS为Zsh。能力接口只返回本机实际找到的Shell；创建接口接收Shell枚举，不接收可执行文件路径。测试构造器仍可启动项目内置合成子进程，用于稳定覆盖输出洪泛、截断与会话撤销，不进入正式界面。

终端创建请求包含尺寸、Shell类型、可选会话名称、可选绝对工作目录及最多32个普通环境变量。工作目录在启动前规范化并验证为现存目录；环境变量名称和值有跨平台边界，值只存在于子进程环境和内存中的创建请求，不写入SQLite或会话摘要。

后台代理持有PTY进程，WebSocket只是可拆卸连接。当前实现支持：

- 会话名称、Shell类型、PID、初始工作目录、状态、普通环境变量数量和退出码；
- 创建、列出、连接、显式断开、自动或手动重连、写入、resize、终止并移除；
- 单调字节游标、64KiB有界回放、截断提示和单写入者租约；
- 浏览器断开后继续运行，重连时从客户端最后确认的游标续传；
- 子进程退出前排空可读PTY尾部，再发布退出事件，避免快速命令丢失最后输出；
- 区分窗口断开、自然退出、强制终止和进程失败。

普通终端可以执行用户命令，但不会自动收到系统凭据库中的秘密。代理进程退出时终端随进程结束；重启后不会伪装恢复旧PTY。MCP终端控制已接入同一会话管理器；`terminal_control.rs`按内部MCP会话标识维护输入租约，正常断开时释放附件，异常断开时由60秒空闲期限及5秒清理周期回收。终端进程不会随附件回收结束。

## 凭据注入扩展合同

凭据任务不能复用“向普通终端写一段已经替换密码的命令”这种实现。应建立独立执行器：

```text
Task request
  -> validate template and ordinary parameters
  -> resolve opaque credential bindings
  -> build process/protocol input in broker memory
  -> execute with timeout and cancellation
  -> redact streaming output
  -> persist only sanitized result and status
  -> clean temporary material
```

任务模板保存凭据插槽与注入策略，不保存解析后的值。支持标准输入、原生协议、临时环境变量、命令参数和短期文件，但每种策略必须有独立实现和测试。参数注入不得通过字符串拼接调用系统 Shell；程序和 argv 应分开构造。

## 流式脱敏器要求

脱敏不能按单个输出块独立查找，因为秘密可能跨 stdout/stderr 分片。实现应：

- 在任务开始时从本次实际使用的秘密构造短期匹配集合；
- 保留最大秘密长度减一的尾部窗口；
- 在输出给 Web、MCP、日志或持久化之前完成替换；
- 覆盖 UTF-8 边界、重复前缀、stdout/stderr 交错、取消尾部和超限截断；
- 任务结束后清除匹配集合和尾部缓冲；
- 使用固定替代标记，不透露秘密长度或类型。

这只能阻止正常输出链中的直接回显，不承诺识别任意编码、加密或主动拆分外传。

## MCP 工具设计

当前 MCP 提供模板发现、策略预检、审批申请/状态、运行创建/状态/取消、安全事件及10个普通终端工具。终端工具通过现有原生IPC调用真实会话，读取提供字节游标、精确字节和UTF-8预览；新增凭据任务模板后，审批请求包含模板ID、普通参数和授权方式；运行创建只包含审批ID与幂等键，不能改写已确认参数。

任何工具都不得包含：

- `get_secret`或等价读取能力；
- 密码、令牌、私钥、Cookie 或认证 Header 字段；
- 由 AI 决定审批结果的接口；
- 已经完成凭据替换的命令文本；
- 未经模板约束的任意带密 Shell。

## 错误与审计

对外错误分为配置无效、未授权、版本冲突、凭据不可用、连接失败、超时、取消、服务中断和未知结果。连接器内部原始错误只用于进程内判断，返回前映射为稳定代码。

审计记录说明谁通过哪个界面请求了哪个模板、何时批准、运行状态和最终结果，不保存秘密、完整命令、原始认证流或未脱敏输出。

## 测试分层

开发阶段随功能运行：

- 领域和迁移单元测试；
- HTTP、WebSocket、MCP 与本机 IPC 集成测试；
- Web 类型检查、组件测试和生产构建；
- 使用合成秘密的分片脱敏测试；
- 连接器的本机或容器化真实服务测试；
- Windows、Linux、macOS 编译与核心行为 CI。

功能基本完整后再集中执行安装身份、敌对同用户、供应链、长时间稳定性和发行签名检查，不把这些检查做成普通用户界面。

## 当前明确限制

- 普通终端提供原始进程输出，不承诺识别或脱敏任意文件中的秘密；
- 只有 PostgreSQL 固定连接检查，没有通用凭据注入引擎；
- HTTP/HTTPS 固定请求、SSH 固定命令、SFTP 单文件传输和 Git HTTPS 固定分支操作已实现，限制见[HTTP 凭据任务](HTTP凭据任务.md)、[SSH 凭据任务](SSH凭据任务.md)及[文件传输与 Git 任务](文件传输与Git任务.md)；Git SSH、MySQL 及数据库查询尚未实现；
- Linux/macOS 凭据库尚未完成完整桌面实机验证；
- 同一操作系统用户下拥有任意代码执行权限的程序可能绕过 SecretBridge；
- 尚无安装包、自动升级、配置备份和恢复入口。
