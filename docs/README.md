## 当前产品边界

- Web 控制台、配置目录、系统凭据库、审批、运行、审计、MCP和本机IPC已经实现；
- PostgreSQL固定只读连接检查已经实现；
- 当前终端仍为合成PTY，真实系统Shell尚未完成；
- 通用凭据注入、SSH、HTTP、MySQL和Git连接器尚未实现；
- 安全验证中心、平台证据、试点准入和试点活动已在schema v12中移除。
