## 当前产品边界

- Web 控制台、配置目录、系统凭据库、审批、运行、审计、MCP和本机IPC已经实现；
- PostgreSQL固定只读连接检查已经实现；
- Web与MCP共用真实终端，通过输入租约协调写入，并支持实时状态刷新；
- 固定程序任务已支持四种凭据注入方式和持续脱敏输出；
- 参数化任务支持普通参数校验、审批快照及单次／限时相同参数授权；
- 原生 HTTP/HTTPS 任务支持请求头与 JSON 请求体凭据代用、普通参数、返回字段筛选及状态码结果，见[HTTP 凭据任务](HTTP凭据任务.md)；
- SSH 固定命令支持可信指纹、密码及私钥协议认证和脱敏输出；SFTP 已支持固定单文件传输；
- Git HTTPS 已支持固定分支远端查询、拉取与非强制推送；Git SSH、MySQL 和数据库只读查询仍待实现；
- 安全验证中心、平台证据、试点准入和试点活动已在schema v12中移除。
