## 如何阅读图表

- **流程图**描述操作先后和结果流向；箭头不代表未经校验的数据可以透传。
- **时序图**描述参与方职责，拒绝与成功路径分别展开。
- **界面图**是交互布局示意，不是实际产品截图。
- **状态图**描述生命周期；恢复连接与重新执行是不同动作。

图表使用GitHub原生Mermaid，详细补充使用折叠区。重要限制和安全警告保持展开，图形之外保留文字解释。

## 文档维护规则

1. 围绕使用、开发、测试和维护任务组织内容，删除与读者目标无关的过程记录。
2. 已实现行为使用明确说明；未实现行为标为设计规范；研究选择标为待验证。
3. 每篇长文提供读者定位、章节导航、示例、边界与下一篇入口。
4. 相同规则保留一个权威位置，其他文档通过链接引用。
5. 示例仅使用合成数据，不嵌入真实账号、目录、目标地址或秘密。
6. 修改行为、接口或支持矩阵时，同一PR更新文档与测试；保持中英文首页一致。
