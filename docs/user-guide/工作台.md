# 工作台使用说明

[文档中心](../README.md) / 工作台

秘桥（SecretBridge）把连接地址、账号和认证整合为一个资源。工作台采用五个入口、主从列表和独立编辑抽屉；审批与身份验证使用居中的模态窗口，操作按钮始终可见。

## 从配置到结果

```mermaid
flowchart LR
    A["资源：地址、账号、认证、用途标签"] --> B["测试连接"]
    A --> C["任务：审阅连接配置与参数"]
    C --> D["审批：核对快照与授权范围"]
    D --> E["执行：状态、数据、脱敏输出"]
    E --> F["历史：运行、终端、会话"]
```

| 入口 | 内容 | 常用操作 |
|---|---|---|
| 资源 | 地址、账号、认证、连接配置、环境及用途标签 | 创建、编辑、写入或清除秘密、测试连接、查看关联任务 |
| 任务 | 任务模板、授权与确认、执行与结果 | 配置操作、审阅快照、批准或拒绝、执行、取消、查看结果 |
| 终端 | 后台持有的真实 Shell | 创建、连接、重连、输入、终止；关闭页面不结束进程 |
| 历史 | 安全日志、运行记录、终端历史、AI 会话 | 搜索、查看输入与输出、下载记录、调整会话审批要求 |
| 设置 | 服务、语言、通知、身份验证、数据维护 | 修改配置、解除页面配对、备份预检、诊断预览及导出 |

## 建立资源

新增时填写名称、地址和凭据即可，其余按“基本信息、连接参数、身份认证、用途与说明”的顺序按需补充。账号、协议选项暂缺也可以保存；连接测试会指出缺少哪些信息，不会猜测数据库名或绕过 SSH 主机核验。

资源只登记一次。名称、类型、环境、说明、地址与账号是可读元数据；密码、API 令牌或 SSH 私钥通过独立写入操作进入本机系统凭据库。页面和 MCP 不提供秘密读回。

用途标签可使用“报表”“开发”“运维”等业务名称，同一资源支持多个标签，不必再建立仅用于分组的连接记录。标签最多 16 个，每项最多 40 字符。环境用于区分开发、测试和生产。

按协议选择连接配置：

- PostgreSQL/MySQL：数据库、端口及 TLS 方式。默认验证证书与主机名，也可明确选择不使用 TLS；关闭后会显示明文传输提示，不会自动降级。
- SSH：端口与已独立核验的主机指纹。测试只认证并断开，不执行远程命令。
- HTTP：无认证、Bearer、Basic 或 API Key 请求头。测试仅发送 HEAD，不跟随重定向；携带认证时必须使用 HTTPS。
- Telnet：须明确确认允许明文协议；此资源不提供握手测试。
- 通用任务：不设置协议检查，可将该资源的认证用于多个明确审阅的任务。

点击 **测试连接** 后显示固定结果代码、耗时和时间，不返回驱动异常或秘密。测试有十秒总截止时间；HTTP 服务拒绝 HEAD 不代表所有业务 API 均不可用。

保存秘密失败时，资源可能已经建立。界面会清空秘密输入并保留已有资源身份，检查后重新输入秘密即可，不要重复创建。修改元数据、轮换认证会使依赖旧版本的审批失效。

## 创建和执行任务

1. 在资源详情选择 **新建任务**，再创建模板。任务会预填资源的地址、账号、协议和认证插槽；核对操作、普通参数、输出范围和超时。
2. 模板保存的是可审阅的配置快照。后续修改资源不会静默改写既有模板；需要编辑模板并重新申请，避免已经批准的目标被悄悄替换。
3. 申请授权，核对模板、普通参数、授权期限及待执行命令。审批队列按申请时间排列；快照变更、终端不可用或模板停用时不能批准。
4. 在 **执行与结果** 选择可用授权启动运行。运行请求使用幂等键去重；网络中断时先查询状态，不要重跑业务操作来补输出。
5. 在资源详情或历史回查结果。退出码与业务结果是不同指标；数据库原生操作没有进程退出码。

AI 提交的一次性命令不进入模板目录。需要复用时由人显式保存为模板；临时终端绑定不会保留，后续仍需重新申请。

## 审批、策略和拒绝反馈

AI 应先读取 `secretbridge_list_catalog.ui_language`，按该语言编写会话摘要、任务名称和申请原因，再登记会话并在后续申请中复用 ID。MCP 只能申请和查询，不能替人修改会话策略。

审批弹窗底部可选择当前 AI 会话的审批要求，再点击批准；策略与本次批准一起提交。拒绝时可填写可选反馈，要求 AI 更换方式或补充信息。AI 应读取 `decision_note`，不能把拒绝当作自动重试许可。

| 要求 | 生效范围 |
|---|---|
| 逐个任务审批 | 每项请求单独确认 |
| 同样任务审批一次 | 固定一小时内复用已批准的同一操作快照及解析后的参数；变化后重新确认 |
| 同一会话审批一次 | 额外勾选风险确认后，此会话未来请求在固定一小时内可自动获批；不限制为同一目标或操作 |

全会话授权不会批量批准已经排队的其他请求，也不会绕过版本校验、执行权限、输出过滤和单次消费规则。页面持续显示高风险提示，可随时撤销未消费的预授权。

页内弹窗独立于通知渠道。浏览器通知需要页面打开及浏览器许可；系统通知由后台发出，仍受操作系统通知权限限制。提醒仅含通用审批信息，后台浏览器不保证获得系统焦点，回到页面可继续处理队列。

## 配对、PIN 与恢复

首次配对由已安装程序的 `open` 命令自动打开一次性本机链接。确认协议后设置至少 6 位、最多 64 位的 PIN/口令，安全保存仅显示一次的恢复密钥，可选绑定身份验证器。不要向 AI 发送 PIN、恢复密钥或验证器配置材料。

页面显示配对剩余时间。期限到达、后台返回过期或从后台切回后确认过期，工作区自动进入登录页面并打开 PIN 验证窗口，不需要刷新。设置页也遵循这一规则。短暂网络故障不会被误判为过期；重新登录后保留工作区位置，但未提交表单需要重新填写，系统不重放旧操作。

浏览器身份验证的变更、诊断解锁或其他要求 PIN 的操作，均先点击动作按钮，再在居中窗口输入 PIN。错误区预留空间，不因提示出现而改变窗口尺寸。连续验证失败会增加等待时间，窗口显示服务端返回的重试倒计时。

恢复密钥入口仅在 PIN 验证失败后出现。恢复成功必须保存新密钥；旧密钥立即失效。解除当前页面配对只撤销该页面身份，不停止后台或终端。

## 历史和数据

安全日志保存固定事件、状态、时间和关联标识；运行记录保存该次执行的脱敏输出和数据。终端历史额外保留创建、交互输入、受控命令配置、普通参数、输出与结束状态，每条记录显示时间，服务重启或移除终端后仍可查阅。

受控命令记录的是批准的精确配置，包括标准输入数据；交互输入记录提交的键盘内容，不伪造经过 Shell 编辑后的命令或逐命令退出码。可按终端、关键词过滤，分页加载并导出当前已加载内容；该导出不宣称包含尚未加载或已轮换的数据。

各执行方式见[凭据命令任务](./tasks/凭据命令任务.md)、[HTTP 任务](./tasks/HTTP凭据任务.md)、[SSH 任务](./tasks/SSH凭据任务.md)、[数据库任务](./tasks/数据库凭据任务.md)和[连续终端](./连续终端.md)。备份不含秘密，恢复需重新录入认证并授权，见[备份与恢复](./备份与恢复.md)。

## 键盘和布局

新增与编辑抽屉从右侧滑入；审批和 PIN 窗口居中。原生 `dialog` 管理焦点，Tab 不离开模态区域，Esc 取消并回到触发位置；提交期间不能关闭，以免误以为请求已取消。窄屏采用上下主从布局及底部导航，长名称换行。

浏览器合成验收检查焦点、错误重试、语言、审批按钮可见性、720/390/320 像素宽度和 200% 缩放。它不代替原生系统凭据库、真实 4K/DPI、屏幕阅读器和后台通知的社区实机验证。
