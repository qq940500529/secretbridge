# 支持矩阵与个人规模性能基线

[文档中心](README.md) / [路线图](../ROADMAP.md) / [开发者入门](开发者入门.md)

本文说明 SecretBridge 开源版本正式支持的运行范围，以及可重复执行的单用户本机性能验收。这里的“支持”表示项目会持续运行自动化回归并接受缺陷报告，不代表企业级容量或无障碍认证。

## 平台与浏览器

| 范围 | 正式支持 | 实验性兼容 | 验证方式 |
|---|---|---|---|
| 操作系统 | Windows 11 x64、Ubuntu 24.04 x64、macOS 14+ Apple Silicon | 其他仍受上游运行时支持的版本或架构 | 三平台构建、原生程序与安装生命周期 CI；稳定版前真实桌面冒烟 |
| 主浏览器 | 当前稳定版 Chromium、Chrome、Edge | Chromium 衍生浏览器 | 完整工作台、连接器、维护和后台控制流程 |
| 辅助浏览器 | 当前稳定版 Firefox | Firefox ESR | 工作台关键流程、键盘、窄屏和焦点恢复 |
| Safari | macOS 当前稳定版 | 上一个主要版本 | 自动化 WebKit 关键流程；真实 Safari 与 Retina 显示检查纳入稳定版桌面冒烟 |
| 显示比例 | 100%—200%，最窄 320 CSS 像素 | 超出范围的系统级放大 | 320/390/720/1440 CSS 像素、减少动态和无横向溢出自动检查；三平台真实缩放冒烟 |

WebKit 自动化可尽早发现 Safari 渲染引擎兼容问题，但不等同于真实 Safari 浏览器、系统字体、钥匙串交互或 Retina 显示器验收。真实设备结果单独记录，不用模拟结果替代。

## 浏览器与基础可访问性验收

项目使用锁定版本的 Playwright，并通过 axe-core 检查工作台主要状态中的 WCAG 2 A/AA 严重与致命问题。自动化还验证：

- 六个主导航入口和完整的凭据—连接—任务—授权—执行—结果闭环；
- 新增与编辑侧边抽屉的键盘焦点约束、Esc 关闭和触发按钮焦点恢复；
- 状态区域、错误区域、跳到主要内容、可辨识表单标签和当前导航状态；
- `prefers-reduced-motion` 下关闭非必要动画；
- 720、390 和 320 CSS 像素布局不出现页面级横向滚动；
- Chromium 完整界面流程，以及 Firefox/WebKit 的关键工作台流程。

```sh
pnpm install --frozen-lockfile
pnpm exec playwright install chromium firefox webkit
pnpm build
python tools/test_browser_acceptance.py
```

报告写入 `dist/browser-acceptance.json`，只包含浏览器名称、脚本名称、耗时和通过状态，不包含页面数据。

## 单用户本机性能门槛

性能脚本启动全新的临时数据目录，不加载业务数据或系统凭据。每轮测量后台首次可用时间、20 次本机状态请求和空闲工作集上限。Chromium 验收另使用完全合成且无凭据的数据，验证 100 个连接、200 个任务和 500 条执行历史下仍可在 2 秒内进入页面、搜索并打开目标记录。

| 指标 | Beta 3 回归门槛 | 解释 |
|---|---:|---|
| 后台启动 p95 | ≤ 5,000 ms | 包含监听器、SQLite 初始化、IPC 与静态资源校验 |
| 本机状态请求 p95 | ≤ 250 ms | 回环请求，不经过系统代理 |
| 空闲工作集 | ≤ 256 MiB | 单个后台进程的最大驻留内存采样 |
| 个人规模界面操作 | ≤ 2,000 ms | 进入列表、搜索并打开目标记录；100 个连接、200 个任务、500 条历史 |

这些门槛用于发现明显退化，不是性能承诺。CI 使用调试构建和共享执行器，因此门槛有意保守；实测值保存在被忽略的 `dist/personal-scale.json` 中。运行方式：

```sh
pnpm build
cargo build --locked
python tools/test_personal_scale.py --rounds 3
```

任务输出洪泛、并发会话、连接器中断和资源释放由[稳定性与故障注入验收](稳定性与故障注入验收.md)负责，避免把同一压力场景在多个脚本中重复实现。

## 真实桌面检查

自动化不能替代以下稳定版前检查：

- Windows 11 在 125% 与 200% DPI 下完成配对、抽屉编辑和任务结果查看；
- Ubuntu 24.04 在 125% 或 150% 分数缩放下完成相同关键流程；
- macOS 14+ Apple Silicon 使用真实 Safari 与 Retina 显示完成关键流程；
- 使用键盘完成主导航、搜索、侧边抽屉提交/取消，并确认焦点位置可见。

Native packages 工作流会在三个目标 runner 上用 release 二进制执行 5 轮测量，并将 `release-personal-scale.json` 与工具链元数据和安装包一起留存 30 天。数值只用于同一流水线条件下发现明显回归，不用于比较不同 runner，也不是用户硬件承诺。

真实安装、系统凭据库和注销/重启恢复仍记录在稳定版桌面冒烟 Issue 中；没有实机证据的平台不得标为已通过。
