# M0验证记录

[文档中心](README.md) / M0验证记录

本文记录已获得的开发证据、当前不支持的环境和仍未解决的风险。它不是生产安全认证。`alpha.19`工程候选加入平台身份与 IPC 固定证据探针；`alpha.20`加入限时试点治理、固定验证矩阵和结项清理门槛；`alpha.21`开始整改闭环，并用本机隔离 PostgreSQL 验证原生适配器的部分TLS、认证与网络失败路径。安装身份、越权主体、目标方授权、完整外部最小权限矩阵和独立评审门槛继续保留。MCP不能作出审批或试点治理决定，业务目标试点和生产使用仍未获验证。

## 当前结论

M0已经验证回环绑定、一次性浏览器配对、精确Origin检查、内存会话、合成PTY独立生命周期、游标重连、单写入者租约、受限输出洪泛、停滞读取、挂起任务取消和三平台构建运行。alpha.11—15依次验证系统凭据写入、固定PostgreSQL链、受限MCP、桥接生命周期和本机IPC；alpha.16建立可重复安全验证；alpha.17建立试点准入；`alpha.19`以schema v10保存平台证据；`alpha.20`以schema v11加入试点治理记录；`alpha.21`补充Windows本机隔离数据库的直接适配器证据。以上均不代表业务目标连接或操作系统身份隔离已经验证。API与界面会直接报告`unverified_same_user`。**三平台全新安装证据、Windows显式DACL、恶意同用户客户端边界以及Linux／macOS凭据库运行验证尚未完成，因此项目仍是同用户兼容模式原型。**

| 范围 | 已有证据 | 当前结论 |
| :--- | :--- | :--- |
| Windows、Linux、macOS构建 | GitHub托管运行器执行格式、Clippy、单元、端到端、Web和许可检查 | 合成原型可构建并运行测试，不等于本机身份隔离通过 |
| 浏览器配对 | 错误令牌、缺少或错误Origin、令牌重放和撤销测试 | 启动令牌一次性使用；页面会话只在内存保存摘要并限时有效 |
| PTY生命周期 | 真实PTY端到端测试覆盖创建、断开、重连和取消 | WebSocket断开不会结束合成进程；服务退出会清理进程 |
| 输出恢复 | 单调字节游标、64 KiB环形保留、越界截断测试 | 重连只补发未读范围；缺失内容被明确标记 |
| 并发输入 | 两客户端端到端测试覆盖独占、只读、接管和释放 | 同一时刻只有一个连接可写入、调整尺寸或通过实时通道终止 |
| 输出与停滞读取 | 真实PTY产生2 MiB合成输出，原连接停止读取；新连接仍可附加并从64 KiB窗口恢复 | 单连接发送最多等待5秒；保留内存有界，超出范围显式截断 |
| 挂起任务取消 | 合成子进程进入30秒等待后，通过控制接口终止并观察终态 | 当前验证单个合成子进程可在5秒验收上限内终止，不代表任意子进程树已验证 |
| Web可访问性基线 | 窄视口导航、跳转主内容、状态播报、键盘可见焦点与减少动态样式 | 静态实现已加入；屏幕阅读器和200%缩放仍需三平台人工验收 |
| Windows系统凭据库 | `keyring`使用一次性随机UUID与合成秘密完成写入、内部读取核对和删除 | Windows Native后端在当前开发机可用；不证明同用户进程隔离，也不替代Linux／macOS验证 |
| MCP独立桥接 | 三平台原生IPC测试覆盖错误令牌、MCP断开、代理继续存活、端点与令牌轮换后重连 | Windows拒绝远程管道客户端；Unix核对对端UID；安装ACL和恶意同用户隔离仍未验证 |

## 当前不支持

- SSH私钥、Cookie、证书私钥及密码／API令牌以外的凭据类型；Linux与macOS系统凭据库尚未完成人工运行验证。
- PowerShell、`cmd`、`sh`、任意用户命令、脚本或业务系统连接。
- 远程访问、反向代理、局域网监听或把回环地址当作身份凭据。
- 服务重启后恢复PTY；当前只保证服务进程存活期间的连接恢复。
- 页面刷新后恢复浏览器会话；令牌不会写入Cookie、LocalStorage或SessionStorage。
- 无图形浏览器的服务器环境；当前启动流程需要成功打开系统浏览器。
- 早于64 KiB保留窗口的完整原始终端记录。
- 浏览器以外的审批管理客户端、MCP审批决定、MCP会话／游标订阅和完整持久审计。

## 剩余风险

1. 服务、浏览器和其他本机程序仍运行在同一交互用户身份下；同身份恶意代码不在当前保护范围内。
2. 托管CI证明三平台合成路径及原生IPC API可运行，不证明专用代理身份、安装后文件／管道ACL、恶意同用户客户端或系统凭据库边界。
3. 64 KiB内存缓冲提供有界恢复，不是审计日志；当前2 MiB场景与5秒发送上限不替代长时间资源浸泡测试。
4. 终端控制序列仍按不可信数据处理；合成程序不产生远程内容，但未来普通终端必须继续禁用自动剪贴板、自动链接和外部资源。
5. 进程强制终止依赖平台PTY实现；仍需在实际桌面系统验证子进程树清理，而不只验证单个合成子进程。
6. IPv6回环、无头环境、休眠／唤醒、浏览器崩溃和长时间运行尚无完整兼容性矩阵。
7. MCP桥接令牌以明文存在应用数据目录的短期连接文件中；同账号恶意程序可能读取该文件。Unix已核对对端UID，Windows已拒绝远程客户端，但显式Windows DACL、安装形态ACL和同用户对抗仍待验证。

## M0剩余退出条件

- 在Windows、Linux和macOS分别验证受控服务身份、管理端身份和非授权客户端之间的实际权限边界。
- 完成长时间资源浸泡、服务崩溃和孤儿进程／进程树清理测试并记录平台资源阈值。
- 完成浏览器键盘、缩放、屏幕阅读器和错误恢复的人工验收。
- 根据证据确认受支持环境；未通过的组合保持明确禁用。
