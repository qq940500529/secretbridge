# 凭据命令

[文档中心](README.md) / [安全连续终端](AI终端与实时状态.md) / 凭据命令

凭据命令是在已有安全终端中执行的精确程序调用。AI 只提交程序、普通参数、连接和不透明凭据引用；本机用户确认后，代理才从操作系统凭据库取出秘密并临时注入。AI 读取到的始终是终端的脱敏结果。

## 推荐流程：AI 动态生成命令

1. AI 调用 `secretbridge_list_catalog`，读取连接地址、账号、类型和凭据是否已配置。这些信息不含秘密。
2. AI 创建或复用一个安全终端，并保存返回的终端 ID。
3. AI 根据连接元数据生成绝对程序路径和逐项参数。秘密位置只能使用独立占位符。
4. AI 调用 `secretbridge_request_command`。该调用只创建待审批草案，不能执行或批准。
5. SecretBridge 打开本机控制台；用户核对终端、程序、工作目录、参数、插槽、连接和有效期，然后批准或拒绝。
6. AI 使用批准记录创建运行，并通过 `secretbridge_read_run_output` 读取该运行保留的脱敏输出；终端实时交互仍使用 `secretbridge_terminal_read`。

用户自建任务模板仍可用于重复操作，但不是使用凭据的前提。动态命令会在内部留下不可变的审批与审计快照，以便说明当时批准了什么。

## 注入方式

| 方式 | 程序收到的内容 | 适用情况与限制 |
|---|---|---|
| `stdin` | 秘密原始 UTF-8 字节 | 优先选择；每条命令最多一个标准输入插槽，不自动添加换行 |
| `environment` | 仅该程序调用期间存在的环境变量 | 可能被同用户调试工具观察；执行后恢复原变量 |
| `argument` | 独立参数中的秘密值 | 只允许完整参数占位符；可能被系统进程查看工具观察 |
| `file` | 指向私有临时文件的路径 | 适合证书或工具原生凭据文件；完成、失败、取消或超时后清理 |

模板或动态请求的秘密位置建议显式写 `{{secret:slot_name}}`（旧式 `{{slot_name}}` 仍兼容）；普通参数中的 `{{.Names}}` 等双花括号文本原样传递，不得拼接秘密，例如：

```json
{
  "terminal_id": "<running-terminal-id>",
  "program": "/usr/bin/example-tool",
  "working_directory": "/tmp",
  "arguments": ["--server", "example.test", "--token", "{{secret:access_token}}"],
  "credential_slots": [
    {
      "name": "access_token",
      "credential_id": "<credential-id>",
      "injection": "argument"
    }
  ]
}
```

程序和工作目录必须已经存在且使用绝对路径。SecretBridge 不通过 Shell 解释参数，也不会自动安装外部程序。单次请求最多 32 个参数和 8 个插槽；单个参数最多 8192 UTF-8 字节，全部参数合计最多 12000 字节。超限会返回字段名、实际长度和上限。

## 终端中的执行方式

代理先把秘密加入该终端的脱敏上下文，再创建权限受限的随机临时文件。写入 PTY 的命令只引用临时文件路径，不包含秘密原文；Unix 默认禁用该终端的持久历史文件，PowerShell 临时环境在调用后恢复。完成标记由代理生成，用于识别退出码，不需要 AI 猜测提示符。

秘密临时文件位于服务数据目录的 `command-secrets` 子目录。Unix 使用 `0700` 目录和 `0600` 文件；Windows 继承私有用户数据目录 ACL。异常清理失败时运行返回 `command_cleanup_failed`，不会伪装成功。删除是常规文件删除，不是磁盘安全擦除。

## 审批与连接类型

审批页面会显示目标终端 ID、程序、工作目录、参数和插槽方式，但不会显示秘密。MCP 没有批准、设置秘密或读取秘密的工具，也不得自动化 Web 控制台。

连接中的地址和账号是帮助 AI 生成命令的普通元数据，不会自动限制网络目标。Telnet 因协议明文传输而默认禁用；只有用户在连接上明确启用不安全协议后才能提交命令。即使启用，仍应优先迁移到 SSH、HTTPS 或其他加密协议。

## 输出与限制

终端原始输出先经过代理的字节级跨分片脱敏，再进入 64 KiB 回放缓冲区和 MCP。非 UTF-8 字节在转为可读文本时会被替换，控制字符不会作为可执行终端指令保存。运行审计只保存固定状态、时间和关联 ID。受控运行另保存最多 2048 个、每个不超过 4 KiB 的已脱敏输出块及记录时间，供运行详情和下载使用；较早块超出保留窗口时会标记截断。它不保存秘密原文或系统异常堆栈。运行结束后可在详情中删除保留输出；删除不会删除运行状态、安全事件或审批快照。

脱敏不是沙箱。目标程序必然能访问注入值，并可能把它写入文件、发送到其他地址或转换成无法识别的形式；同用户调试工具也可能观察进程。只批准可信程序和最小范围命令。服务重启会中断当前终端与运行，不会自动重放。

## 一次性草案与保存

MCP 动态命令和结构化 SSH 请求创建一次性草案。草案不出现在可复用模板列表中，仍随审批和运行保留在本机数据库中作为当时的审计快照；关闭终端后，旧终端草案会显示不可用，不能重新提交或批准。若需复用，用户可在审批详情中显式选择“保存为模板”；保存会创建不绑定临时终端的新模板；复用时在代理管理的隔离进程中执行，并重新走正常审批，绝不沿用旧审批。

结构化 SSH 请求使用已保存连接和其密码凭据引用，必须提交用户确认过的 SHA256 主机密钥指纹。代理在建立连接时严格核验指纹，不接受未知主机密钥。连接和凭据引用中同时填写了地址或用户名时必须一致。
