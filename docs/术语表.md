# 术语表

[文档中心](README.md) / 术语表

以下定义用于密桥的产品说明与工程规范。涉及权限时，以具体操作策略和安全模型为准。

| 术语 | 定义 | 容易混淆的边界 |
| :--- | :--- | :--- |
| 凭据 Credential | 认证使用的密码、令牌、私钥等秘密 | 凭据引用不是秘密值，也不应自动授予权限 |
| 执行代理 Broker | 校验授权并在内部使用凭据的可信组件 | 不等于开放给助手的任意shell |
| 目标 Target | 受控连接对象及端点、协议、信任配置 | 不能由未授权参数随意重定向 |
| 操作模板 Action | 固定执行器、参数schema、权限和输出策略 | 可执行文件路径固定不代表其内容可信 |
| 审批 Approval | 对特定请求范围的授权决定 | 不是永久、跨目标或跨会话授权 |
| 会话 Session | 跨请求保留的执行上下文 | session_id是定位标识，不是认证令牌 |
| 输入租约 Input lease | 同一终端当前唯一的输入控制权 | 观察会话不等于可以写入 |
| PTY | 伪终端，承载交互程序的输入输出 | 渲染终端文本的组件不负责进程保活 |
| ConPTY | Windows伪控制台机制 | 不适用于Linux/macOS的平台实现 |
| IPC | 本机进程之间的通信 | 本机连接同样需要身份与权限校验 |
| MCP | 助手与工具通信的协议 | 协议本身不替应用完成凭据授权 |
| 幂等键 | 标识同一逻辑请求、避免重复执行的键 | 不能证明断线时远端操作没有发生 |
| 事件cursor | 安全事件流的读取位置 | 不能绕过事件归属和访问控制 |
| 结构化放行 | 只释放已声明、获授权的结果字段 | 不等于任意stdout先返回再事后打码 |
| 脱敏 Redaction | 过滤可识别的敏感内容 | 不能识别所有变换、编码与隐蔽外传 |
| 失败关闭 Fail closed | 无法确认安全时拒绝执行或释放结果 | 不自动降级到明文存储或无认证连接 |
| 对应源码 Corresponding Source | 许可证定义的构建、修改等所需源码范围 | 不等于用户密码或客户数据库 |
| SBOM | 软件物料清单，记录发行内容及依赖 | 有清单不表示许可证或漏洞审核完成 |
| DCO | 贡献者对提交来源与权利的声明 | 不等于版权转让或第三方审计 |
