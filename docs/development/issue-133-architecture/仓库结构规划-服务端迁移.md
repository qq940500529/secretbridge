# 仓库结构规划：服务端逐文件迁移

[总览](./仓库结构规划.md) · [职责边界](./仓库结构规划-职责与契约.md) · [其他文件迁移](./仓库结构规划-其他文件迁移.md) · [验证方案](./仓库结构规划-验证方案.md)

本表是 issue #133 的目标状态。左侧路径相对于现有 `crates/secretbridge-server/src/`，右侧路径相对于目标 `backend/src/`，除非另有说明。`A + B` 表示原文件按职责拆入两个目标文件，不是保留复制品；当前 #133 本地草稿中的同名文件也遵循相同归属。允许实施中增加必要文件，但不得留下未说明归属的旧壳。

## 入口、领域与应用

| 当前文件 | 目标文件 | 具体归属 |
|---|---|---|
| `lib.rs` | `lib.rs` + `runtime/composition.rs` + `application/sessions.rs` + `application/execute_run.rs` + `adapters/http/*` | 根仅导出；`AppState` 装配、会话、运行用例、路由分别拆开 |
| `main.rs` | `main.rs` + `cli/mod.rs` + `cli/synthetic_child.rs` | 根仅解析到 CLI 入口；合成子进程逻辑独立 |
| `catalog.rs`／本地草稿 `catalog/mod.rs` | `domain/{credentials,targets,actions,approvals,runs,events,policy}.rs` + `adapters/persistence/mod.rs` | 模型和枚举进 domain；连接与 SQL 进 persistence；`SyntheticRun` 等历史内部类型改为准确的 `Run`，对外字段保持契约 |
| `parameters.rs` | `domain/parameters.rs` | 参数定义、值及纯校验唯一归属 |
| `credential_service.rs` | `application/manage_credentials.rs` | SQLite/密钥链双写协调、失败补偿、不可执行中间态 |
| `postgres_run.rs` | `application/postgres_check.rs` | 连接检查运行的状态、取消和完成编排 |
| `redaction.rs` | `application/redaction.rs` | 流式与跨分片秘密过滤；执行器返回前统一调用 |
| `totp_auth.rs` | `application/totp.rs` + `adapters/http/auth.rs` | TOTP 生成/验证与 HTTP 处理器分离 |
| `maintenance.rs` | `application/backup_restore.rs` + `adapters/persistence/maintenance.rs` | 操作协调与数据库读写分离 |
| `runtime.rs` | `runtime/control.rs` + `adapters/http/runtime.rs` | 生命周期控制不包含 HTTP 提取器 |
| `diagnostic_startup.rs` | `runtime/diagnostics.rs` | 启动故障记录与安全类别 |
| `lifecycle.rs` | `cli/mod.rs` | 安装、启动、停止命令分发 |
| `lifecycle/installation.rs` | `cli/installation.rs` | 安装、升级、回滚和卸载 |
| `lifecycle/startup.rs` | `cli/startup.rs` | 启动探测、自启动及状态 |

`application/ports.rs` 是新文件，只声明用例真正需要的存储、秘密值、执行与终端能力。`runtime/composition.rs` 是唯一装配点；用例接收其所需端口，而不是到处传完整 `AppState`。`domain/mod.rs`、`application/mod.rs` 和 `runtime/mod.rs` 只明确导出模块，不重新堆业务实现。

## HTTP 与 MCP 入站

| 当前文件 | 目标文件 | 具体归属 |
|---|---|---|
| `http_api/mod.rs`／原 `lib.rs` 的路由段 | `adapters/http/{mod,router,dto,errors}.rs` | Router 组合、请求/响应形状和错误映射分离 |
| `http_api/auth.rs`／原 `lib.rs` 的认证段 | `adapters/http/auth.rs` | 配对、Origin、会话、TOTP HTTP 入口 |
| `http_api/catalog_routes.rs`／原 `lib.rs` 的目录段 | `adapters/http/{catalog,approvals}.rs` | 凭据引用、目标、模板、审批端点 |
| `http_api/runs.rs`／原 `lib.rs` 的运行段 | `adapters/http/runs.rs` + `application/execute_run.rs` | 端点与执行用例分离 |
| `http_api/terminal_routes.rs`／原 `lib.rs` 的终端段 | `adapters/http/terminals.rs` | WebSocket/HTTP 边界，不实现 PTY 管理 |
| `http_api/tests.rs`／原 `lib_tests.rs` | `adapters/http/tests.rs` + `application/*` 相邻单元测试 | 端点验证与纯用例验证分开 |
| `approval_notifications.rs` | `adapters/http/notifications.rs` | 通知设置路由和 DTO |
| `browser_auth_events_api.rs` | `adapters/http/auth.rs` 或 `events.rs` | 身份事件查询，按最终路由资源归属 |
| `conversation_api.rs` | `adapters/http/conversations.rs` | AI 对话资源路由 |
| `maintenance_api.rs` | `adapters/http/maintenance.rs` | 备份、恢复、配置路由 |
| `maintenance_api/diagnostics.rs` | `adapters/http/diagnostics.rs` | 诊断导出与解锁路由 |
| `maintenance_api/tests.rs` | `adapters/http/tests.rs` | 保留完整行为测试，不再通过父模块私有状态共享 |
| `mcp.rs` | `adapters/mcp/{mod,tools,contracts,errors}.rs` + `adapters/native_ipc/*` | 工具层与本机桥接彻底分开 |
| `mcp/contracts.rs`／原 `mcp.rs` DTO 段 | `adapters/mcp/contracts.rs` | MCP 输入输出契约，序列化测试相邻 |
| `mcp/conversation.rs` | `adapters/mcp/conversation.rs` | 会话工具语义 |
| `mcp/errors.rs` | `adapters/mcp/errors.rs` | MCP 错误码和下一步提示 |
| `mcp/ready.rs` | `adapters/mcp/ready.rs` | 连接就绪检查，不掺业务初始化 |
| `mcp/guidance.md` | `adapters/mcp/guidance.md` | 简短服务器说明，长流程仍在 Skill |
| `mcp/bridge_response.rs` | `adapters/native_ipc/protocol.rs` | 桥接响应的协议与错误封装 |
| `mcp/native_bridge.rs` | `adapters/native_ipc/{client,server,protocol,permissions,unix,windows}.rs` + `backend/local-access/src/{windows,unix}.rs` | 客户端、服务端、帧/令牌与平台端点分离；目录/连接文件/端点权限归跨平台窄组件 |
| `mcp/tests.rs`／原 `mcp_tests.rs` | `adapters/mcp/tests.rs` + `adapters/native_ipc/tests.rs` | 工具 schema 与桥接权限/拒绝测试分开 |

MCP 工具注册只调用应用用例；CLI 可使用 native IPC 的生命周期控制，但本机桥接令牌不进入工具结果。HTTP 与 MCP 的相同业务动作最终进入同一个授权、版本及取消逻辑。

| `crates/secretbridge-windows-pipe-acl/src/lib.rs` | `backend/local-access/src/windows.rs` | Windows 管道、目录、文件 ACL FFI 在后端内部的跨平台权限组件中单独审阅；Unix 权限实现新增于 `unix.rs` |

所有迁移前后的持久化 schema 数值与内容、公开 API/MCP/IPC 形状、操作语义均由[可执行验证方案](./仓库结构规划-验证方案.md)核对；表中的“移出”不等于删除功能。
