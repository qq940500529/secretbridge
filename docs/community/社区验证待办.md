# 社区验证待办

[文档中心](../README.md) / 社区验证待办

本页跟踪需要真实桌面、人机交互或更多操作系统组合才能补充的证据。[0.3.0-beta.1 社区验证任务](https://github.com/qq940500529/secretbridge/issues/139) 汇总了本版可认领的实机检查。实现类 Issue 可在代码、自动化检查和文档达到验收要求后关闭；本页中的人工复核与三平台扩展验证不单独阻止关闭。这里的“待验证”不代表已通过，也不代替稳定版发布门槛。

欢迎社区认领一项或一组场景，提交带有版本、系统、步骤、实际结果和清理情况的反馈。仅使用合成凭据与非私人目标；截图和日志需删除用户名、主机名、地址、本地路径、凭据、PIN 与验证码。安全漏洞走[私密报告](../../SECURITY.md)。
