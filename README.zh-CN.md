# 密桥 SecretBridge

**AI提出操作，本机受控代用凭据，只返回经过审查的结果。**

[English](README.md) · [开发设计](docs/开发设计.md) · [路线图](ROADMAP.md) · [安全报告](SECURITY.md)

## 当前状态

项目已按Windows、Linux、macOS三平台规划。当前公开的是设计文档、开源治理文件及仓库检查工具，**没有可运行应用、已实现UI、密码库或安装包**。请勿录入真实密码；三平台CI仅检查仓库文档与检查工具，不代表桌面软件已兼容三平台。

拟采用Tauri 2＋Rust＋React/TypeScript＋xterm.js。Windows使用ConPTY；Linux/macOS使用POSIX PTY。凭据、本地通信、进程监督与权限隔离均按平台实现，不将Windows API直接移植到其他系统。

## 用户体验目标

- 清晰的总览、凭据、目标、终端、审批与审计界面；浅色／深色主题，中英文可切换。
- 初次使用从模拟连接开始，依次配置目标、审批并查看结果，不要求先理解MCP或系统服务。
- 多会话终端、断线恢复、输入权提示；关闭UI不等于关闭后台任务。
- 明确区分普通终端与受控凭据操作；密码不进入AI接口、可见命令行或原始日志。
- 可访问性、跨平台快捷键、DPI与多屏适配作为验收项，不只追求截图效果。

## 安全边界

输出打码不是安全隔离。AI若具有凭据所有者同账号的任意执行能力，仍可能绕过软件取密。真实凭据试点必须先通过系统权限隔离验证；开发阶段只使用合成凭据。没有“任意命令自动填密且保证不泄漏”的承诺。
